# React + Vite

i have made an AI Movie Analyzer which is an AI Film Tracker That Reads Your Movie Reviews and Tells You What Kind of Movies You Love.
It is a digital film diary where users log the movies they watch along with short personal reviews.
Once the user builds a history, they can click “Analyze My Taste” to activate the AI engine.
The system sends the full review dataset to an AI model, which behaves like a film critic and identifies hidden patterns in the user’s preferences.
The goal is to reveal what kinds of stories, emotions, genres, and cinematic themes the user is naturally drawn to over time.
I have used React , Tailwindcss, vite openrouter , and OMDB to make this project.
it has some interesting features like when the user has added the name of a movie the official poster will be appeared automatically.
